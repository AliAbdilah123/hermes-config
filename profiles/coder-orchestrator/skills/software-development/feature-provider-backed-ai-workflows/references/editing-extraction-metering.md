# Editing, extraction, metering

Editing: persist user message, stream provider, persist assistant only on success; retain note ID/range/original text and revalidate before apply; serialized autosave flushes on switch/navigation. Extraction: persist upload/signature, durable job, strict JSON schema, editable review, transactional finalize with ownership. Metering: conditional debit and run/usage insertion in one transaction; cancel only active runs; pricing/model allowlists are versioned policy.
