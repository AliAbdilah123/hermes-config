# Delivery-scope overrides

Before committing, pushing, deploying, or publishing, honor the latest explicit scope instruction over any default delivery workflow.

- “Implement in the current branch” identifies where to edit; it does not authorize commit or push.
- If the user says “do not commit or push,” continue local implementation and verification, then report changed files and fresh verification results without either action.
- Apply mid-turn scope corrections immediately and acknowledge them briefly.
